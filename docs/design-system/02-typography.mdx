## 1. Font Family

```ts
import { fontFamily } from '@ds'
```

| 이름 | 폰트 스택 | 용도 |
|------|-----------|------|
| `fontFamily.sans` | **Inter**, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto … | 모든 UI 텍스트 (기본) |
| `fontFamily.mono` | **JetBrains Mono**, Fira Code, Cascadia Code, Menlo … | 코드 블록, `<code>`, `<pre>` |

### 로드 방법 (`index.html`)

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link
  href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap"
  rel="stylesheet"
/>
```

|-------|----|---------|

## 7. Text 컴포넌트

> **파일**: `src/design-system/components/Typography.tsx`

MUI `Typography`의 얇은 래퍼로, color alias와 편의 prop을 추가합니다.

### Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `variant` | Variant | `'body1'` | 위 6번 표의 variant |
| `color` | ColorAlias \| string | `'primary'` | 아래 color alias 참조 |
| `clamp` | number | — | 말줄임 줄 수 (WebkitLineClamp) |
| `inline` | boolean | `false` | `true`면 `<span>`으로 렌더 |
| `as` | ElementType | — | 렌더링 HTML 태그 오버라이드 |

### Color Alias

| alias | → MUI color | 실제 값 |
|-------|------------|---------|
| `primary` | `text.primary` | `#171717` |
| `secondary` | `text.secondary` | `#737373` |
| `disabled` | `text.disabled` | `#a3a3a3` |
| `inverse` | `common.white` | `#ffffff` |
| `link` | `primary.main` | `#6366f1` |
| `success` | `success.main` | `#22c55e` |
| `error` | `error.main` | `#ef4444` |
| `warning` | `warning.main` | `#f59e0b` |
| `info` | `info.main` | `#3b82f6` |

### 사용 예시

```tsx
import { Text } from '@ds'

// 기본 variant
<Text variant="display">히어로 대제목</Text>
<Text variant="h1">페이지 제목</Text>
<Text variant="h2">섹션 제목</Text>
<Text variant="h3">서브 섹션</Text>
<Text variant="body1">본문 텍스트입니다.</Text>
<Text variant="body2">작은 본문 텍스트</Text>

// color alias
<Text variant="body2" color="secondary">보조 설명</Text>
<Text variant="caption" color="disabled">비활성 텍스트</Text>
<Text variant="body1" color="link">링크 스타일 텍스트</Text>
<Text variant="body2" color="success">성공 메시지</Text>
<Text variant="body2" color="error">오류 메시지</Text>

// 말줄임 (2줄)
<Text variant="body1" clamp={2}>
  이 텍스트는 2줄을 초과하면 말줄임표(…)로 잘립니다.
</Text>

// 인라인
<Text variant="body2" inline>인라인 </Text>
<Text variant="body2" color="link" inline>링크</Text>
<Text variant="body2" inline>처럼 보입니다</Text>

// 코드
<Text variant="code">const greeting = "hello"</Text>

// overline (섹션 레이블)
<Text variant="overline" color="secondary">CATEGORY</Text>

// as prop — h1처럼 스타일, p 태그로 렌더
<Text variant="h2" as="p">시맨틱 태그 오버라이드</Text>
```

## 8. 직접 MUI Typography 사용 시

테마에 커스텀 variant가 등록되어 있으므로 MUI `Typography`에서도 사용 가능합니다.

```tsx
import { Typography } from '@mui/material'

<Typography variant="display">대제목</Typography>
<Typography variant="code">const x = 1</Typography>
```
