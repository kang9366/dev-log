## Web Vitals를 실험 지표로 쓰는 이유

기능 개발은 A/B 실험으로 검증하면서 **성능 최적화**는 여전히 감으로만 평가하는 팀이 많습니다. Web Vitals를 실험 지표로 편입시키면:

- 최적화 전후 효과를 **정량적**으로 증명 가능
- 비즈니스 KPI와 성능 지표의 상관관계 파악
- 회귀(regression)를 조기에 감지

---

## Core Web Vitals 핵심 정리

| 지표 | 이름 | 측정 대상 | Good |
|------|------|---------|------|
| **LCP** | Largest Contentful Paint | 가장 큰 콘텐츠 로딩 시간 | ≤ 2.5s |
| **INP** | Interaction to Next Paint | 상호작용 응답 속도 | ≤ 200ms |
| **CLS** | Cumulative Layout Shift | 레이아웃 누적 이동 | ≤ 0.1 |

## 수집 설정

```ts
// lib/vitals.ts
import { onLCP, onINP, onCLS, type Metric } from 'web-vitals'

interface VitalsPayload extends Metric {
  experimentId: string
  variant: 'control' | 'treatment'
  userId: string
}

function sendToAnalytics(payload: VitalsPayload) {
  // navigator.sendBeacon은 페이지 이탈 시에도 안전하게 전송
  navigator.sendBeacon('/api/vitals', JSON.stringify(payload))
}

export function trackVitals(
  experimentId: string,
  variant: 'control' | 'treatment',
  userId: string,
) {
  const base = { experimentId, variant, userId }

  onLCP(metric => sendToAnalytics({ ...metric, ...base }))
  onINP(metric => sendToAnalytics({ ...metric, ...base }))
  onCLS(metric => sendToAnalytics({ ...metric, ...base }))
}
```

## 실험 설계 원칙

### 1. 단일 변수 원칙

```
❌ 이미지 최적화 + 코드 스플리팅 + 폰트 변경 동시 적용
✅ 이미지 최적화만 적용 → LCP 변화 측정
```

### 2. 샘플 크기 계산

통계적으로 유의미한 결과를 얻으려면 충분한 샘플이 필요합니다.

```
최소 샘플 수 = (Z² × p × (1-p)) / E²

Z = 1.96  (신뢰도 95%)
p = 0.5   (보수적 추정)
E = 0.05  (오차 범위 5%)
→ 최소 385 세션 / 그룹
```

### 3. 측정 기간

| 상황 | 권장 기간 |
|------|---------|
| 트래픽 적음 (< 1만 DAU) | 2주 이상 |
| 보통 (1~10만 DAU) | 1주 |
| 많음 (> 10만 DAU) | 3~5일 |

## 분석 쿼리 예시 (BigQuery)

```sql
SELECT
  variant,
  APPROX_QUANTILES(lcp_value, 100)[OFFSET(75)] AS lcp_p75,
  APPROX_QUANTILES(inp_value, 100)[OFFSET(75)] AS inp_p75,
  AVG(cls_value) AS avg_cls,
  COUNT(*) AS sessions
FROM vitals_events
WHERE experiment_id = 'image-optimization-v2'
  AND DATE(created_at) BETWEEN '2025-10-01' AND '2025-10-14'
GROUP BY variant
```

> Google은 Web Vitals를 **p75(75번째 백분위수)** 기준으로 평가합니다. 평균보다 p75를 사용하세요.

## 마무리

Web Vitals를 A/B 실험 지표로 활용하면 성능 최적화의 비즈니스 가치를 증명할 수 있습니다. 핵심은 **단일 변수 격리**와 **통계적 유의성** 확보입니다.
