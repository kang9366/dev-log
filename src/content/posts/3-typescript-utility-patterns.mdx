## 들어가며

TypeScript의 Utility Types는 타입을 변환하고 조합하는 강력한 도구입니다. 실무에서 자주 쓰이는 7가지 패턴을 코드 예시와 함께 정리합니다.

---

## 1. `Pick` — 필요한 속성만 선택

```ts
interface User {
  id: number
  name: string
  email: string
  password: string
  createdAt: Date
}

// 공개 API 응답에서 password 제외
type PublicUser = Pick<User, 'id' | 'name' | 'email'>
// → { id: number; name: string; email: string }
```

---

## 2. `Omit` — 특정 속성 제거

```ts
// DB 저장 전 id, createdAt 제외
type CreateUserDTO = Omit<User, 'id' | 'createdAt'>
// → { name: string; email: string; password: string }
```

| 패턴 | 특징 | 적합한 상황 |
|------|------|-----------|
| `Pick` | 포함할 키를 명시 | 필요한 필드가 적을 때 |
| `Omit` | 제외할 키를 명시 | 제외할 필드가 적을 때 |

---

## 3. `ReturnType` — 함수 반환 타입 추출

```ts
async function fetchUser(id: number) {
  const res = await fetch(`/api/users/${id}`)
  return res.json() as Promise<User>
}

// 반환 타입을 별도로 정의하지 않아도 됨
type FetchUserResult = Awaited<ReturnType<typeof fetchUser>>
// → User
```

---

## 4. `satisfies` — 추론 유지하며 타입 검증 (TS 4.9+)

```ts
const palette = {
  red:   [255, 0, 0],
  green: '#00ff00',
  blue:  [0, 0, 255],
} satisfies Record<string, string | number[]>

// ✅ 타입 검증은 통과하면서도 각 값의 타입은 보존됨
palette.red   // → number[]  (string | number[]가 아님)
palette.green // → string
```

> `as const`와 달리 `satisfies`는 값의 구체적인 타입을 유지합니다.

---

## 5. `Discriminated Union` — 상태 모델링

```ts
type RequestState<T> =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'success'; data: T }
  | { status: 'error'; error: string }

function renderPost(state: RequestState<Post>) {
  switch (state.status) {
    case 'loading': return <Spinner />
    case 'error':   return <Alert>{state.error}</Alert>
    case 'success': return <PostCard post={state.data} />  // ✅ data 타입 보장
    default:        return null
  }
}
```

## 6. `Template Literal Types` — 동적 이벤트 타입

```ts
type EventName = 'click' | 'focus' | 'blur'
type HandlerName = `on${Capitalize<EventName>}`
// → 'onClick' | 'onFocus' | 'onBlur'

type Handlers = {
  [K in HandlerName]?: () => void
}
```

---

## 7. `Branded Types` — 원시값 구별

```ts
// string이지만 서로 다른 용도를 타입으로 구별
type UserId   = string & { readonly _brand: 'UserId' }
type PostId   = string & { readonly _brand: 'PostId' }

function createUserId(id: string): UserId {
  return id as UserId
}

function getPost(postId: PostId) { /* ... */ }

const userId = createUserId('u-123')
// getPost(userId) // ❌ 컴파일 에러 — 타입 불일치
```

## 마무리

이 패턴들은 런타임 에러를 컴파일 타임에 잡아줍니다. 특히 `satisfies`와 `Discriminated Union`은 복잡한 상태 관리를 타입 레벨에서 안전하게 표현하는 데 매우 유용합니다.
